# smart-grain-storage-system
IOT and AI -based smart grain storage system for monitoring and preventing grain spoilage.
There we use AI model to predict a grain spoilage before happen it.
AI model trained by Google Colab.
System gives three notification about grain status,those status are safe,warning and critical.
There we use ESP32,DHT22,DS18B20,IR sensor,OLED,Buzzer,LEDs,GSM SIM800L,RTC Module.
